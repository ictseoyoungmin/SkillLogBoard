# .skilllog Control Plane

This directory stores local, inspectable files for agent-assisted research workflows.

- `agent_skills.md`: workflow guidance and completion criteria.
- `experiment_plan.md`: editable research topic, data, metrics, and experiment axes.
- `rules.md`: project-level rule guidance, compatible with the existing Skills.md philosophy.
- `report_spec.md`: v0.7 report artifact specification.

Legacy root-level `Skills.md` remains supported. The `.skilllog/` files are additive and do not
enable built-in LLM inference or automatic code generation.
