# SkillLogBoard v1.1.2 Showcase, Visual Parity, and Demo Depth Development Plan

## Purpose

v1.1.2 addresses the gap between implemented capability and perceived capability.

The current UI is intentionally minimal, but users may interpret hidden controls as missing features. This milestone makes capabilities discoverable without returning to a crowded dashboard.

## Core Problem

The Live Board can look sparse when:

- only one run is loaded
- only two metrics exist
- no report artifacts exist
- no agent files exist
- no events/rules/logs exist
- compare mode is not activated
- drawers/trays are collapsed
- demo data is too simple

## Design Strategy

1. Make demo data richer.
2. Show compact capability hints.
3. Improve action-oriented empty states.
4. Improve metric/compare visual hierarchy.
5. Add visual parity and screenshot QA guidance.
6. Keep all evidence local and file-backed.
