SkillLogBoard Docs

v0.2 provides a static-first single-run dashboard. v0.3 provides the MVP Skills.md rule engine. v0.4 provides static multi-run compare reports. v0.5 provides lightweight research templates. v0.6 is the release-hardening candidate. v0.7 adds report artifact packages. v0.8 adds local agent research workflow files and checks.

Rule Status

MVP Supported: required_config, required_metric, metric_threshold, best_last_gap, artifact_required.

Implemented templates: ir-drop, trajectory.

Planned templates: classification, segmentation, finance-dashboard. Optional integrations remain optional and are not required by the core install.

Planned rules: dashboard_panel, domain_breakdown.

Agent Research Layer

v0.8 provides .skilllog control files, agent action logs, handoff notes, decisions, and local completion checks. It does not include built-in LLM inference, cloud sync, or automatic code generation.
